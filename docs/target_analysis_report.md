## Conclusion

Primary target selected (PROVISIONAL): **`creator_relative_log_views` @ `performance_target_v0_1`**.
Rationale: highest coverage among exposure-corrected candidates, robust to
the extreme view outlier (median-based baseline), interpretable in log units,
usable for both pointwise and within-creator pairwise labels.
Caveats on this pilot set: corr(target, creator baseline) = -0.411
(with n=16 this is not distinguishable from the mechanical coupling between a
leave-one-out residual and its small sibling pool); the age-adjusted residual
model fits poorly (see R^2 above), so `performance_residual` remains secondary
until real repeated-snapshot data from issue #8 supports a better age model.

**Status: exploratory.** Snapshots here are synthetic stand-ins; final
primary-target selection and coverage numbers must be re-confirmed on real
issue #8 pilot snapshots before dataset freeze.
